# Reclaim 1.5.2

- Fix the app icon's inset appearance with a full-canvas macOS asset catalog.
- Replace unreliable “never opened” app recommendations with recorded usage,
  observed launches, and explicitly labeled large apps with unknown usage.
  Discover nested installations such as Unity.
- Preserve history on read/decode failures, serialize concurrent writes, retain
  backups, and distinguish quarantined storage from verified disk recovery.
- Add scan stages, elapsed time and estimated remaining time.
- Make “Why this?” and sparkle actions open AI explanations, including API-key
  setup when needed. Remove the duplicate contents button.
- Allow whole user applications to be selected in My Mac, while protecting
  app internals and running applications. Move permission checks off the UI thread.
- Offer individual Messages attachment review by size/age instead of selecting
  the entire attachment collection. Keep app-quit checks current and precise.
- Explain Full Disk Access for the current app copy and provide a way to reveal it.
- Put the simplified live diagram inside Activity. Both views use the same
  process groups, resource measurements and actionable insights.

Scans, previews and cleanup retain their existing pricing. BYOK AI remains
available; prepaid hosted AI and storage billing are not enabled in this release.
